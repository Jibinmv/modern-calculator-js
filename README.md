🧮 CalcFlow — Modern JavaScript Calculator

A clean, responsive, and visually appealing calculator built with HTML, CSS, and JavaScript.CalcFlow provides essential arithmetic operations through a simple modern interface with a gradient background and easy-to-use buttons.



📌 Project Description

CalcFlow is a beginner-friendly frontend project created to practice JavaScript fundamentals, DOM manipulation, event handling, and basic UI design.

The calculator supports common arithmetic operations such as addition, subtraction, multiplication, division, percentage calculations, decimal values, and clearing/deleting input.

✨ Features

➕ Addition

➖ Subtraction

✖️ Multiplication

➗ Division

% Percentage operation

🔢 Decimal number support

🧹 AC button to clear the calculator

⌫ DEL button to remove the last entered value

🎨 Modern gradient-based user interface

📱 Responsive and user-friendly layout

⚡ Built using vanilla JavaScript — no external frameworks required

💻 How It Works

Enter numbers using the calculator buttons.

Select an arithmetic operator.

Enter the next number.

Press = to calculate the result.

Use AC to reset the calculator.

Use DEL to remove the last input.
